## 📌 Project Overview

**EduTrack** is a Java-based educational management application designed to provide a structured approach to managing educational information.

The project focuses on applying core Java programming concepts, maintaining organized application architecture, and implementing efficient data handling techniques.

EduTrack demonstrates how Java can be used to develop structured applications with a clear separation of source code, application data, and compiled output.

## 🎯 Project Objectives

- Develop a structured Java-based educational application.
- Apply object-oriented programming principles.
- Improve code organization and maintainability.
- Understand application data management.
- Implement modular programming practices.
- Gain practical experience in Java application development.
- Strengthen problem-solving and programming skills.

## ✨ Key Features & Highlights

- **Java-Based Development:** Developed using Java programming.

## ⚙️ Prerequisites

Before running the application, ensure that you have:

- Java Development Kit (JDK 17 or later)
- Git installed on your system
- A Java-compatible IDE or code editor
- Basic knowledge of Java programming

Verify your Java installation:

```bash
java -version
javac -version
```

## 🚀 Installation & Execution

Follow these steps to download and run the project locally.

### Step 1: Clone the Repository

```bash
git clone https://github.com/RajaHithesh/EduTrack.git
```

### Step 2: Navigate to the Project Directory

```bash
cd EduTrack
```

### Step 3: Compile the Java Source Files

```bash
javac -d out src/edutrack/*.java
```

### Step 4: Run the Application

```bash
java -cp out edutrack.Main
```

### Execution Notes

- Run all commands from the root directory of the project.
- Ensure Java is correctly installed and configured in the system PATH.
- Verify that the main class is named `Main`.
- If the entry-point class has a different name, replace `edutrack.Main` with the correct fully qualified class name.
- If additional packages or external dependencies are used, include them during compilation and execution.
